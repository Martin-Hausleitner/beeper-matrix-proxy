Patch Command

Browsers intentionally hide the absolute local file path. After choosing a file, run the command below and replace the placeholder with the selected image path from Finder. 

node scripts/patch_beeper_desktop_bridgev2_icon.cjs --image /absolute/path/to/icon.png
