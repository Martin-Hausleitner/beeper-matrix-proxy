# Historical evidence metadata

[historical-artifacts.json](historical-artifacts.json) records the paths, byte
counts and SHA-256 digests of 18 historical artifacts from the earlier source
revision. Their contents are withheld from the current source distribution.
The records contain no source payloads and cannot be executed as scripts or
installed as service configurations.

The artifacts were not re-executed or independently accepted by this review.
Their former filenames and historical assertions do not establish current
provider connectivity, delivery, runtime health or product E2E acceptance.
Current product verification remains **NOT_RUN** for this evidence directory.

The previous collection included private material and malformed or incomplete
historical files. It is represented by metadata rather than repaired into a
new claim of successful execution. Current code tests must report their own
source revision, environment and observed result separately.

This source-tree correction does **not** remove earlier published Git history,
pull-request versions, caches or existing copies. The historical exposure
therefore remains an owner follow-up. No Git history has been rewritten and no
original outside the review checkout has been removed.
